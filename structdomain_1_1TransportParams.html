Detailed Description

Параметры всех видов транспорта.

Содержит скорости, стоимости и интервалы. Значения по умолчанию используются как fallback при отсутствии CSV. Реальные значения загружаются из transport_params.csv через GraphBuilder::buildTransportParams().
