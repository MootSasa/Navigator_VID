# Структура CSV файлов

### 1. `nodes.csv` — Узлы графа

Этот файл описывает все точки на карте: перекрестки, остановки, станции метро, входы в здания.

**Структура:**
`node_id,type,name,x,y`

| Поле      | Тип        | Описание                                                                  | Пример                                     |
| :-------- | :--------- | :------------------------------------------------------------------------ | :----------------------------------------- |
| `node_id` | `int`      | Уникальный целочисленный идентификатор узла.                              | `101`                                      |
| `type`    | `string`   | Тип узла: `intersection`, `bus_stop`, `metro_station`, `poi` (точка интереса). | `bus_stop`                                 |
| `name`    | `string`   | Человекочитаемое название. Может быть пустым для перекрестков.             | `"Остановка 'Библиотека им. Ленина'"`        |
| `x`, `y`  | `float`    | Координаты на карте для UI и A*.                           | `55.7512`, `37.6128`                       |

**Пример `nodes.csv`:**
```csv
101,intersection,"",55.750,37.610
102,bus_stop,"Ост. 'Университет'",55.702,37.530
103,metro_station,"Ст. м. 'Университет'",55.703,37.531
104,poi,"Главное Здание МГУ",55.703,37.530
```

### 2. `edges.csv` — Рёбра графа

Этот файл описывает все связи между узлами.

**Структура:**
`edge_id,from_node,to_node,transport_type,length_meters,name`

| Поле             | Тип      | Описание                                                                                           | Пример                             |
| :--------------- | :------- | :------------------------------------------------------------------------------------------------- | :--------------------------------- |
| `edge_id`        | `int`    | Уникальный ID ребра. Нужен для связи с расписаниями.                                               | `2001`                             |
| `from_node`      | `int`    | ID начального узла.                                                                                | `101`                              |
| `to_node`        | `int`    | ID конечного узла.                                                                                 | `102`                              |
| `transport_type` | `string` | Тип транспорта: `walk`, `car`, `bus`, `metro`, `taxi`.                                             | `walk`                             |
| `length_meters`  | `float`  | Длина ребра в метрах.                                                                              | `150.5`                            |
| `name`           | `string` | Название ребра (улица, номер автобуса, линия метро).                                               | `"ул. Ленина"`, `"Авт. 255"`, `"Линия 1"` |

**Пример `edges.csv`:**
```csv
2001,102,104,walk,100,"Пешком до МГУ"
2002,104,102,walk,100,"Пешком от МГУ"
2003,102,103,walk,50,"Пересадка на метро"
3001,101,102,bus,2500,"Авт. 113"
4001,101,104,car,3000,"Проспект Вернадского"
```
*Для двустороннего движения нужно создавать два ребра: A->B и B->A.*

### 3. `transport_params.csv` — Параметры способов перемещения

Этот файл содержит глобальные константы для каждого типа транспорта. Позволяет менять цены и скорости, не перекомпилируя программу.

**Структура:**
`transport_type,param_name,param_value`

| Поле           | Тип      | Описание                                                               |
| :------------- | :------- | :--------------------------------------------------------------------- |
| `transport_type` | `string` | Совпадает с `transport_type` из `edges.csv`.                           |
| `param_name`   | `string` | Имя параметра: `speed_kmh`, `ticket_price`, `fuel_consumption` и т.д. |
| `param_value`  | `string` | Значение параметра.                                                    |

**Пример `transport_params.csv`:**
```csv
walk,speed_kmh,5.0
walk,fatigue_per_km,10.0
car,speed_kmh,40.0
car,fuel_consumption_l_per_100km,8.0
car,fuel_price_rub_per_l,50.0
bus,speed_kmh,25.0
bus,ticket_price,55.0
metro,speed_kmh,50.0
metro,ticket_price,55.0
metro,morning_evening_interval_min,2.0
metro,day_interval_min,5.0
taxi,price_per_km,20.0
taxi,base_price,150.0
```

### 4. `schedules.csv` — Расписания для динамических рёбер

Этот файл добавляет динамическое поведение конкретным рёбрам.

**Структура:**
`edge_id,schedule_type,params`

| Поле          | Тип      | Описание                                                                       | Пример                               |
| :------------ | :------- | :----------------------------------------------------------------------------- | :----------------------------------- |
| `edge_id`     | `int`    | ID ребра из `edges.csv`, к которому применяется расписание.                     | `3001`                               |
| `schedule_type` | `string` | Тип расписания: `fixed_times` (для автобусов), `time_window` (для мостов).       | `fixed_times`                        |
| `params`      | `string` | Параметры, зависящие от типа. Для `fixed_times` — это список времен через запятую. | `"08:00,08:15,08:30,..."`              |

**Пример `schedules.csv`:**
```csv
# Расписание для автобусного маршрута с edge_id = 3001
3001,fixed_times,"08:00,08:15,08:30,08:45,09:00"

# Разводной мост (например, ребро с id = 5001)
# Ребро будет недоступно с 01:00 до 05:00
5001,time_window,"05:00-01:00" 
```
